# Stage3 Main/Live 새 K(K_D23) 진단 기본값 변경 마감

기준일: 2026-11-21 (Asia/Seoul)

이 문서는 새 K(`K_D23`, 정책 목록의 표시명 K)의 Live 진단 구성 기본값을 `PSEUDO`에서 `NONE`으로 바꾼 결정과 그 범위, 검증, 한계를 적는다. 선택 정책은 바뀌지 않았다. 커밋 SHA와 원격 확인은 이 문서에 적지 않는다.

## 1. 결정

- 사용자 결정(2026-11-21): 새 K Live의 진단 구성 기본값을 `NONE`으로 한다. 환경 변수 `MINESWEEPER_K_D23_DIAGNOSIS`가 없거나 빈 값이면 `NONE`이다.
- 기본 구성에서는 pseudo 50/50 진단과 linked 풀림 진단을 계산하지 않는다. 추측 결정의 K 설명 창 진단 칸에는 “이 구성에서는 계산하지 않았다. 계산하지 않은 것이며 진단 결과가 아니다.”가 나온다.
- pseudo의 Live 사용 방식 개선(입력 경로에서 분리, 설명 창을 펼칠 때만 계산, 화면 설정 추가 등)은 이번에 하지 않았다. 전시회 이후 검토 과제다(7절).

## 4. 수동으로 켜고 끄는 방법

구성은 자동 진행의 worker를 시작할 때 앱의 환경에서 한 번 읽는다. 앱을 시작하기 전에 지정하거나 해제한다. 화면의 설정이 아니다.

PowerShell, 작업 위치는 저장소 루트. 이렇게 지정한 값은 그 PowerShell 창을 닫을 때까지 남는다.

```powershell
$env:MINESWEEPER_K_D23_DIAGNOSIS = 'PSEUDO'
& 'C:\venvs\minesweeper\Scripts\python.exe' -B .\main.py
```

기본(`NONE`)으로 돌아오려면 아래로 해제하거나 그 창을 닫고, 앱을 다시 시작한다. 해제됐는지는 `Test-Path Env:MINESWEEPER_K_D23_DIAGNOSIS`가 `False`인지로 확인한다.

```powershell
Remove-Item Env:MINESWEEPER_K_D23_DIAGNOSIS
```

Git Bash, 작업 위치는 저장소 루트. 명령 앞에 붙인 지정은 그 명령에만 적용되고 셸에 남지 않는다.

```bash
MINESWEEPER_K_D23_DIAGNOSIS=PSEUDO "/c/venvs/minesweeper/Scripts/python.exe" -B main.py
```

`export`로 지정했다면 `unset MINESWEEPER_K_D23_DIAGNOSIS`로 해제한다.

- `PSEUDO` 대신 `PSEUDO_LINKED`를 쓰면 linked 진단도 계산한다. 세 값 말고는 거부되고 그 자동 진행은 시작되지 않는다.
- README의 실행 방법이 함께 지정하는 다른 환경 변수(`PYTHONDONTWRITEBYTECODE`, `GIT_OPTIONAL_LOCKS`, `QT_QPA_PLATFORM`)는 그대로 쓴다.
- 소스가 바뀌었으므로 이 변경을 받은 뒤에는 앱을 다시 시작한다(전송 버전은 10 그대로다).

## 6. 한계

- pseudo를 꺼도 추측 결정에서는 간격이 늘 수 있다. 추측에서는 전방 비교(최소 위험 동률 2~8칸일 때, 호출 한도 72회)와 더 큰 실행 검증이 들어간다. 2절의 계측에서 입력 7은 전방 가정 계산 18회를 했고, 진단 없음에서도 고정 간격 200 ms 가운데 고정 간격 대기가 12.5 ms만 남았다. 더 큰 상태에서는 200 ms를 넘을 수 있다.
- 2절의 수치는 판 하나, 입력 0~8, 구성마다 5회의 값이다. 간격의 약 9%는 범주로 나누지 못했다. 비표시 화면의 창은 실제 창보다 작았고, 계측 도구가 부모 프로세스에 준 부하는 따로 재지 않았다. worker의 모듈 출처는 시작 명령과 같은 시작 형태의 확인으로 간접 확인했다.
- 이 변경의 검증은 제한 검증이다. 전체 회귀를 실행하지 않았고, pseudo 진단 자체의 시험은 코드가 바뀌지 않았음을 확인했을 뿐 이번에 실행하지 않았다.
- 기본 구성에서 pseudo 진단의 내용(조건이 성립한 쌍, 하한)은 화면에 나오지 않는다. 보려면 4절의 방법으로 켠다.
- 진단 구성은 환경 변수로만 바꾼다. 화면의 사용자 설정이 아니다. `PSEUDO_LINKED` 구성의 native는 확인하지 않았다.
- 사용자의 native 확인(다시 시작한 앱에서 “계산하지 않았다” 문구, 켰을 때의 pseudo 문장, 해제 뒤 복귀)은 사용자가 2026-11-21에 확인해 알려 준 결과다(세 항목 통과). 이 변경 작업의 실행 측이 화면을 직접 본 것이 아니다.
- 추측 직전 멈춤의 위치와 이유에 대한 관찰 기록은 전달받지 않았다.
